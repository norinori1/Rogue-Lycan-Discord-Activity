# カード一覧

- **殺害（攻撃）（レアリティ: N）**: 対象のHP -1。
- **騎士（防御）（レアリティ: N）**: 対象をその夜の「殺害」から守る（自分可）。
- **医者（回復）（レアリティ: N）**: 対象のHP +1。上限突破可。上限突破の効果は2日間持続。
- **占い（調査）（レアリティ: N）**: 対象の最終的な陣営を判別（偽装カードとの読み合いあり）。2つ使用して、「偽証」貫通。
- **上級国民（政治）（レアリティ: N）**: 翌昼の投票で自分の投票権 +1（スタック可能）。
- **選挙干渉（政治）（レアリティ: N）**: 対象の投票権を無効化（使用者は朝に通知される）。
- **譲渡（流通）（レアリティ: N）**: 自分のスタック内カード1枚を他プレイヤーに渡す（協力・共謀）。
- **偽札（妨害）（レアリティ: N）**: 外見は譲渡だが渡ったカードは無効化。相手のスタックを妨害。
- **反転（特殊）（レアリティ: UR）**: 自分の陣営を入れ替える（低確率）。使用時は朝に全体へ通知。
- **JOKER（特殊）（レアリティ: UR）**: 任意のカードと交換可能（極低確率）。
- **「狂暴化(攻撃)」（レアリティ: N）**:「攻撃」「妨害」属性カード出現重み+1。
- **「市民化(政治)」（レアリティ: N）**:「政治」「流通」「回復」「調査」属性カード出現重み+1。
- **「ピエロ」（レアリティ: N）**:「特殊」属性カード出現重み+1。
- **「正義の鉄槌(攻撃、特殊)」（レアリティ: UR）**（低確率出現）対象1体を選択し、それが**「使用者と同一陣営」**ならば、対象に 2ダメージ を与え、このカードを使用者の手札に 返還 する。
- 対象が**「使用者と異なる陣営」**ならば、代わりとして 使用者が2ダメージ を受け、このカードは消費される。
- **「強欲な壺(流通)」（レアリティ: N）**:ランダムに手札にカードを2枚追加する。
- **「市民革命(特殊)」(レアリティ: N)** - この夜において「政治」属性カード無効化します。
- **皇帝（特殊 / Rare: UR）**

「玉座に座る者は一人。新たな王の誕生は、旧き王の死を意味する。」
効果:
[1]プレイヤーを最大3人選ぶ（選ばれた者と全体に通知）。
[2]皇帝の勝利時には、選ばれたプレイヤーも勝利する（同陣営である必要なし）。
[3] 皇帝が「殺害」カードを使用した夜、選ばれたプレイヤーが「殺害」カードを使用していた場合、そのプレイヤーの対象を**「皇帝の対象」と同一に変更**する。
[4]【易姓革命】: すでに皇帝が存在する場合、その皇帝の道連れ効果を無効化した上で、前の皇帝を即座に死亡させる。

- **「パン屋(特殊)」(レアリティ: N)**

[1] このカードを持っている間、朝になるたびにパンが1つ焼かれます（ログで表示）。誰がパンを焼いたかは公開されません。
- **偽証(妨害)**(レアリティ: N)**: 自分の陣営が参照されたとき、このカードが自動的に使用され、その参照結果を市民に上書き（例: 占いで人狼を占っても市民と表示）。スタックから自動発動し、使用後は消費される。
- **捜査(調査)**(レアリティ : N) : 3日前の夜の殺害行動の犯人を特定する。
- **独裁者(政治)**(レアリティ: UR) : 自分以外のプレイヤー全員の投票権を0にする（使用者は朝に通知される）。このカードが使用された夜、選挙干渉カードは無効化される。このカードを使用時、「政治」属性カードを全体で合計1枚以上使われたならば、この効果を無効化する。
- **スパイ(特殊)**(レアリティ : N)
  - 対象1プレイヤーの所持カードを全て確認する。この効果は通知されない。
