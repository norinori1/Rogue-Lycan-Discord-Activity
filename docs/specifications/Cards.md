# カード一覧 (v2)

## レアリティ別出現率
- **N (Normal)**: 78%（基本アクション・役職継承）
- **R (Rare)**: 15%（環境変更）
- **UR (Ultra Rare)**: 7%（切り札・盤面破壊）

---

## 1. 環境カード (レアリティ: R)
**【属性: 環境】** - 出現確率: 1枠あたり 15%。
- 仕様: 夜フェーズに使用。環境カードは並行して2枚以上有効にできるようにする。
- ログにおいて、「環境」カードの使用はログに目立つように通知される
- 持続: 発動した夜の処理から、翌昼フェーズ終了（追放投票）まで有効。

- **高度経済(環境、流通)**: 次の夜、全員のカード構築フェーズでの選択肢を **3枚 → 4枚** に増やす。
- **濃密の森**: 「調査」属性カード（占い、捜査等）が **50%の確率で失敗** する。
- **古戦場**: 「攻撃」属性カード（殺害等）は、「防御」属性カード（騎士等）を **無効化** する。
- **鎖国**: 「流通」属性（譲渡、偽札、強欲な壺、高度経済 等）が **すべて不発** になる。
- **救済の雨**: 翌朝、生存者全員の **HPを +1** する（上限突破不可）。
- **戒厳令**: 翌昼フェーズ、全員の **発言可能回数（または発言時間）を半分** に制限する。

---

## 2. 切り札カード (レアリティ: UR)
- **開示（特殊、環境）**: 全プレイヤーのスタック（手札）を **全員に公開** した状態でプレイする。
- **死の雨（特殊、環境）**: 使用した瞬間に、自分を含む生存者 **全員のHPを -1** する。
- **反転（特殊）**: 自分の陣営（市民⇔人狼）を入れ替える。使用時は朝に全体通知。
- **JOKER（特殊）**: 任意のカード1枚と交換可能。
- **正義の鉄槌（攻撃/特殊）**: 対象が自分と同陣営なら 2ダメージ与えカード返還。別陣営なら自分が 2ダメージ受けカード消費。

---

## 3. 基本カード (レアリティ: N)
- **殺害（攻撃）**: 対象のHP -1。
- **騎士（防御）**: 対象をその夜の「殺害」から守る（自分可）。
- **医者（回復）**: 対象のHP +1。上限突破可（効果は2日間）。
- **占い（調査）**: 対象の陣営を判別。2枚同時使用で「偽証」を貫通。
- **捜査（調査）**: 3日前の夜の「殺害」行動の犯人を特定する。
- **スパイ（特殊）**: 対象1名の所持カードをすべて確認する（通知なし）。
- **上級国民（政治）**: 翌昼の自分の投票権 +1（スタック可）。
- **選挙干渉（政治）**: 対象の投票権を無効化する。
- **譲渡（流通）**: 自分の手札1枚を他人に渡す。
- **偽札（妨害）**: 譲渡に見せかけて、無効化されたゴミカードを渡して相手の枠を埋める。
- **偽証（妨害）**: 【自動発動】占われた際に「市民」と誤認させる。
- **強欲な壺（流通）**: 山札からカードを2枚ドローする。
- **市民革命（特殊）**: この夜の「政治」属性カードをすべて無効化する。
- **パン屋（特殊）**: 保持している間、毎朝「パンが焼けた」ログが出る（誰かは不明）。
- **狂暴化 / 市民化 / ピエロ**: それぞれ「攻撃・妨害 / 政治・流通・回復・調査 / 特殊」属性の出現率を上げる。
- **投資(流通)** : 次の夜のカード構築フェーズで、選択肢を **+1**する。
