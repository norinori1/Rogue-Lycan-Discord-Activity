# ROGUE-LYCAN — 仕様要約

## 概要
- **コア概念**: 「人狼」×ローグライク（夜ごとのビルド）、リソース管理（HP・スタック）を組み合わせた非対称対戦ゲーム。
- **特徴**: ゲーム開始時は全員弱体（能力なし）。毎夜3択で能力を獲得し、スタックで蓄積・任意発動して戦う。

## 基本パラメーター
- **HP**: 初期値2。0で脱落（死亡）。`医者`で上限を突破して回復可能（回復は有効期限2日）。
- **スタック（手札）**: 獲得したカードを保持。使用タイミングは任意。(最大手札枚数 : 5枚)
- **陣営**: 市民 / 人狼（各プレイヤーはいずれかに所属）。

## ゲームサイクル
- **夜：構築フェーズ** — 各プレイヤーにクライアントで3枚提示。1枚を選びスタックへ。
- **夜：行動フェーズ** — スタックからカードを選んで使用（自分を対象に含め可能）。
- **朝：判定・通知フェーズ** — HP0の者を公開。反転は発動事実を通知。選挙干渉は投票時まで秘匿。
- **昼：議論・投票フェーズ** — 生存者で議論→投票。最多票は追放（即死またはHP減少）。

## 夜のアクション処理優先順位（サーバーロジック）
1. JOKER / 譲渡 / 偽札：手札の移動・変換を確定。
2. 反転：陣営変更を確定（以降の判定は変更後の陣営に基づく）。
3. 騎士：防御対象を確定。
4. 殺害 vs 医者：HP変動を計算（例: 2 -1 +1 = 2）。
5. 占い：最終的な陣営で結果を返す。
6. 選挙干渉 / 上級国民：翌昼の投票パラメータを設定。

## 戦術的ポイント
- **自傷・自演**: 自分に殺害を使い市民のフリをするブラフが可能。
- **タンクビルド**: 医者でHPを重ね、「殺せない市民」を作る。
- **ステルス票操作**: 選挙干渉の秘匿性により濡れ衣戦術が可能。
- **トロイの木馬**: 偽札を譲渡のふりで渡して決定的瞬間に無効化するコンボ。
